## ⛔ `taylor_thedy_logo.png` — mockup gerado por IA, NÃO é a marca

Storefront fictício (prédio de tijolos, calçada arborizada, marca escrita
"TaylorThedy" num Didot serifado). Entrou no repo em 2026-07-17 e foi tratado
como referência oficial por engano nos D-79/D-80.

**Custo do engano:** o lockup cromado que foi para produção derivava daqui — ou
seja, o site publicado exibiu uma marca que não é a da barbearia. Além disso,
três rodadas de edição raster tentaram "consertar" a placa a partir dele, e uma
sessão chegou a concluir (erradamente) que a placa com o "t" não existia.

Mantido apenas como registro histórico. **Não usar para nada.**

Ver `docs/site-publico/UI_SPEC_V3.md` §1 e a memória
`logo-fachada-placa-inexistente`.
